## 面板服和 VPS 游戏云差在哪：三条边界决定你该买哪个

最硬的一条是能不能挂插件框架。官方论坛教程写得很直白：VPS 支持挂 Robot 框架、支持群组服、支持 MCDR，代价是需要有开服经验；MCSM 面板服「便宜、小白一键开服，不能群组/挂 Robot 框架」。想在一个入口下挂多个子服（登录服、生存服、小游戏服分开），或者要用 MCDR 做自动备份、指令转发这类自动化，面板服这条路走不通，只能买 VPS 游戏云自己搭。

第二条是系统权限。VPS 游戏云给完整系统权限，Linux 或 Windows 都能选，SSH、RDP、VNC 都能用；面板服没有系统级登录权限，能改的只有面板里开放的那些开关，换服务端核心、传插件、改配置文件、重启，这些够用，但你想装个别的软件或者改环境变量就没门。

第三条是网络形态。面板服走 NAT 共享 IP，靠端口映射对外，第三方测评整理的说法是给 10 个端口、固定 50Mbps 上行；VPS 游戏云可以直接拿独立公网 IP。这两点的差别在实际使用里很具体：NAT 机器发给朋友的地址是「IP:端口」而不是默认的 25565，端口换了地址就得重发。

| 能力 | MCSM 面板服 | VPS 游戏云 |
| --- | --- | --- |
| 开服方式 | 网页选服务端，一键开 | SSH/RDP 自己装环境 |
| 群组服 | 不支持 | 支持 |
| MCDR / Robot 框架 | 不支持 | 支持 |
| 网络 | NAT 共享 IP + 端口映射 | 可配独立公网 IP |
| 上手门槛 | 零基础可用 | 需要开服经验 |
| 价格 | 更低 | 更高 |

判断起来不复杂：一个人或一个小圈子开一个标准服，面板服；要群组、要 MCDR、要在一个机器上跑好几个服务端，VPS。论坛那篇 2022 年的基岩版教程也是这个口径，它直接写「此教程适用于面板服，方便朋友间联机。如果是想要开公共服务器，建议购买 VPS」。

硬盘不用买大。教程原话是生电服 50G 存档盘完全够用，「甚至 30G 也可以」。存档体积主要看地图跑了多久、有没有装大量生成结构的模组，正常生存服几十 G 能撑很久，真不够了面板上加盘比重买机器便宜。

## 固定计费还是动态计费：两种建议的适用场景不一样

官方论坛教程的建议是选固定计费，「全程火力全开」，思路是性能优先，不用担心 CPU 跑满之后账单跟着涨，适合 24 小时有人、随时可能上线的服。

第三方测评里给的是另一种算法：动态计费基础租金低，CPU 使用率超过 20% 的部分按「CPU 电量」日结，1 CPU 电量大约等于 30% CPU 跑 1 分钟，单价在 0.0005~0.001 元这个量级，系统每天还送一定免费电量。白天没人、晚上开几小时的服，动态计费确实更省。

两种说法不冲突，判断依据是你的服有没有明显的空窗期。学生党晚上和周末才聚，动态；服务器长期挂着、随时可能有人进，固定。中大型服不要为了省这点钱选动态，半夜 CPU 打满的时候账单会教你做人。

## 开服实操：买完之后四步，卡住多半在端口映射

购买路径：登录雨云 → 点「游戏云-购买」→ 选配置 → 类型选 MCSM → 付款 → 进「云产品-游戏云」→ 管理 → 重装/切换游戏。

服务端选择上，教程推荐 Purpur 端。它还提了一句，更推荐 Folia 多线程优化端，但需要自己重装 Java 环境、自行上传，而且支持的插件不多。对新手来说 Purpur 是性价比最高的起点。

重装完进面板：信息与监控 → 管理面板 → 找到实例 → 开机，等启动完成。

**第四步是 NAT 端口映射，不做就进不去游戏。** 公网 IP 的机器跳过这步，直接用公网 IP 进。NAT 机器在控制台选中实例，进「网络设置」，添加端口映射规则：

- **外部端口**：公网访问用的端口，一般随机生成即可
- **内部端口**：填实例上实际运行服务的端口，也就是面板上显示的那个实例端口，改过就填改后的
- **协议**：MCJE 选 TCP，MCBE 选 UDP，Steam 选 UDP，Windows 远程桌面选 TCP 或 tcp_udp

保存之后把 IP 和外部端口发给朋友。进不去先查两件事：内网端口填错没有，外网端口是不是被占了。都排除了还进不去，开工单。

**换存档**：面板里点「文件」，找到 `worlds` 文件夹，把里面原有文件清空，上传自己的存档，重启服务器。这条来自论坛的基岩版教程，Java 版同样适用。
